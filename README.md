# The Funniest One-Line Resignation Letter

A TypeScript program (Node 22) that writes one resignation letter, in the voice of a retry loop that has had enough, to `/output/entry.txt` — at most 140 characters, one line, no wasted words.

Run it with:

```sh
node main.ts
```
